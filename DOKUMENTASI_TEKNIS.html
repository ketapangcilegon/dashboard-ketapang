Sistem Informasi Geospasial, Peramalan Harga Komoditas Strategis, & Pendukung Keputusan Intervensi Ketahanan Pangan Kota Cilegon
Diterbitkan: Juni 2026 | Versi Dokumen: 2.2.0 | DKPP Kota Cilegon

1. Pendahuluan & Gambaran Umum

Aplikasi Dashboard Ketahanan Pangan Kota Cilegon (diakses publik via https://pangancilegon.web.id) dikembangkan sebagai perangkat pemantauan, analisis statistik, peramalan harga berbasis kecerdasan buatan, dan pendukung keputusan spasial (Decision Support System/DSS). Dashboard ini membantu Dinas Ketahanan Pangan dan Pertanian (DKPP) Kota Cilegon dalam mendeteksi gejolak harga pangan, mengukur indeks kerawanan pangan (FSVA), memetakan prevalensi balita underweight (SKPG), serta menyalurkan intervensi pasar murah dan paket pangan secara optimal di tingkat kelurahan.

Fokus Utama Solusi:

  • Scraping real-time harian dari portal SAGON untuk melacak harga pangan.
  • Pemodelan peramalan harga masa depan 10 komoditas strategis menggunakan algoritma machine learning (TypeScript murni).
  • Penetapan lokus intervensi kelurahan terarah memanfaatkan algoritma Borda Count Desil.
  • Penghasil laporan otomatis (Executive Insight) bertenaga model bahasa Gemini AI.

Aplikasi dirancang dengan arsitektur serverless modern berbasis Next.js untuk skalabilitas dan efisiensi operasional tinggi:

Komponen Teknologi / Library Deskripsi & Peran
Framework Utama Next.js 16.2.6 (App Router), React 19.2.4 Penyedia routing dinamis, optimasi static-regeneration (ISR), dan Serverless API Route.

Integrasi AI Google Gemini API (gemini-2.5-flash-lite) Mesin analisis naratif yang menghasilkan ringkasan situasi pangan secara dinamis per wilayah.

5. Formulasi & Metodologi Perhitungan

Aplikasi ini mengadopsi standar baku nasional BAPANAS untuk analisis kerawanan pangan (FSVA), rasio gizi nasional untuk SKPG, serta teknik statistik multivariat untuk model ML dan pemeringkatan prioritas kelurahan.

A. Klasifikasi Prioritas FSVA (IKP)

Skor IKP (Indeks Ketahanan Pangan) kelurahan dipetakan ke dalam 6 status kerentanan sesuai ambang batas Badan Pangan Nasional:

  • Prioritas 1 (Sangat Rentan) : $\text{IKP} < 46.37$
  • Prioritas 2 (Rentan) : $46.37 \le \text{IKP} < 53.95$
  • Prioritas 3 (Agak Rentan) : $53.95 \le \text{IKP} < 61.83$
  • Prioritas 4 (Agak Tahan) : $61.83 \le \text{IKP} < 69.71$
  • Prioritas 5 (Tahan) : $69.71 \le \text{IKP} < 77.29$
  • Prioritas 6 (Sangat Tahan) : $\text{IKP} \ge 77.29$

B. Prevalensi Kerawanan Gizi Balita (SKPG)

Rasio balita gizi kurang di tingkat kelurahan dihitung bulanan berdasarkan klasifikasi prevalensi underweight (BB/U):

Rasio Underweight (%) = [ (Gizi Kurang + Gizi Sangat Kurang) / Total Balita Diukur ] x 100

Ambang batas untuk penentuan status warna pada layer peta WebGIS:

  • RENTAN (Merah) : Rasio > 15.0%
  • WASPADA (Kuning) : 10.0% ≤ Rasio ≤ 15.0%
  • AMAN (Hijau) : Rasio < 10.0%

C. Pemeringkatan Prioritas Intervensi (Borda Count)

Metode Borda Count menggabungkan peringkat kerentanan struktural jangka panjang (FSVA) dan kerawanan gizi jangka pendek (SKPG) menjadi skor tunggal pembuat kebijakan. Langkah perhitungannya adalah:

  1. Peringkat Parsial IKP: Seluruh kelurahan diurutkan dari nilai IKP terkecil ke terbesar. Wilayah terkecil mendapatkan peringkat Rank_FSVA = 1 (paling rentan).
  2. Peringkat Parsial Gizi: Seluruh kelurahan diurutkan dari rasio underweight terbesar ke terkecil. Wilayah terbesar mendapatkan peringkat Rank_SKPG = 1 (paling rentan).
  3. Jumlahkan Peringkat (Borda Sum):
    Borda_Sum = Rank_FSVA + Rank_SKPG
  4. Urutan Akhir: Urutkan kelurahan berdasarkan Borda_Sum secara menaik (ascending). Wilayah dengan skor terkecil berada di posisi teratas sebagai prioritas intervensi utama.
  5. Desil Borda (D1 - D10):
    Desil = Min(10, Ceil( (Rank_Akhir / Total_Kelurahan) * 10 ))
    D1 s.d D5 diklasifikasikan sebagai Prioritas Intervensi, sedangkan D6 s.d D10 tergolong Tahan Pangan.

D. Model Aditif Peramalan Prophet-like & OLS Solver

Model peramalan didasarkan pada formulasi linear aditif multivariat yang direkayasa dalam TypeScript murni. Sebanyak 25 fitur dinormalisasi menggunakan transformasi Z-score:

z = (x - μ) / σ

Persamaan parameter linier diselesaikan menggunakan OLS (Ordinary Least Squares) normal equation:

(XTX)β = XTY

Skrip menyelesaikan vektor bobot $\beta$ dengan metode LU Decomposition & Gaussian Elimination dengan partial pivoting. Peramalan melangkah ke depan (T+1 s.d T+3) diselesaikan secara rekursif.

6. REST API Utama

Backend Next.js mengekspos endpoint API berikut untuk manajemen data dan otomasi:

Method Path Endpoint Payload / Parameter Fungsi Utama
GET /api/harga-sagon - Scrape otomatis harga pangan harian dari portal SAGON dengan retries 7 hari ke belakang.
POST /api/etl-ml - Menjalankan sinkronisasi data inflasi BPS & cuaca BMKG, lalu memicu training ulang ML.
GET /api/ml/predict - Mengembalikan daftar hasil prediksi harga (T+1 & T+3) untuk seluruh komoditas strategis.
GET /api/ml/explain ?komoditas=harga_beras Mengembalikan analisis pengaruh fitur (driver) dan narasi detail EWS.
POST /api/ai-insight { tahun, bulan, kec, kel } Memanggil Gemini API untuk membuat analisis naratif eksekutif regional.
